Solution explanation:
The methods , , and have been removed from since version 1.0 Now, to add a uniformly-controlled Pauli-Y rotation to your circuit, you have to do it as follows:

```
ucrx()
```

```
ucry()
```

```
ucrz()
```

```
QuantumCircuit
```

```
from qiskit.circuit.library import UCRYGate angles = [np.pi / 4, np.pi / 2, 3 * np.pi / 4, np.pi] controls = [0, 1] target = [2] circ.append(UCRYGate(angles), controls + target)
```
