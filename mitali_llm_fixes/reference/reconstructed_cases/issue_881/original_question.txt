Solution explanation:
Your problem has to do with the way you think the oracle in the reference you linked to works. It's operation is a bit subtle. In that circuit, after the Hadamard gates you have the superposition state: $$|\psi\rangle = \frac{1}{\sqrt{2^3}}\big(|000\rangle+|001\rangle+|010\rangle+|011\rangle+|100\rangle+|101\rangle+|110\rangle+|111\rangle \big) .$$ Now, the following operation is a $CZ$ gate with the control in the bottom qubit and the target in the top qubit. What I think you expect from this gate is for it to only mark state $|101\rangle$, but this operation actually flips the phase of any state that has the first and last qubit equal to $1$. That includes both $|101\rangle$ and $|111\rangle$. So why does this circuit in particular work? Well, because the following gate is a $CZ$ gate with its control in the middle qubit and target in the top qubit. Your expectation is probably that this will only mark state $|110\rangle$, but as before, this gate flips the phase of any state where the first two qubits are $1$, that includes states $|110\rangle$ and $|111\rangle$. This means that the phase of state $|111\rangle$ was flipped twice, taking it back to a positive phase. So at the end, only states $|101\rangle$ and $|110\rangle$ end up with a negative phase: $$|\psi\rangle = \frac{1}{\sqrt{2^3}}\big(|000\rangle+|001\rangle+|010\rangle+|011\rangle+|100\rangle-|101\rangle-|110\rangle+|111\rangle \big) .$$ What you seem to want is a circuit that only marks state $|11001001\rangle$. You can do this, by replacing your oracle definition as:

```
MultiCZ = ZGate().control(num_ctrl_qubits=qubits-1, ctrl_state='11001001') qc.append(MultiCZ, range(qubits))
```

