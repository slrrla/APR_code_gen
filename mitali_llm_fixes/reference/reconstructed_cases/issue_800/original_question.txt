Solution explanation:
I took a closer look under the hood of qiskit, and I think I've discovered the issue. It looks like Qiskit uses the library to do their concurrency/parallelization. There seems to be some kind of a conflict with uses the library together with the library. I was able to get my code to work by switching from to futures to handle my parallelization. The only changes that need to be made for the above code to work are to add and replace with .
