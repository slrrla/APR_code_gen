Solution explanation:
When , the first thing that the function does is checking whether both and are valid quantum states. In particular: if you pass a statevector $| \psi \rangle$, it checks that $\langle \psi | \psi \rangle = 1$ (unit norm) if you pass a density matrix $\rho$, it checks that $tr(\rho) = 1$ and that $\rho$ is positive semidefinite As you already figured out, in your case, is a instance but it's not positive semidefinite and that's why fails. However, you can compute the fidelity with no errors setting . Qiskit allows this because, in some cases like maybe yours, you may want to get the fidelity between objects that are not necessarily valid quantum states (e.g. affected by some form of noise). EDIT: also, note that and can simply be numpy arrays or Python lists. So, creating the from your array is an unnecessary step because the conversion occurs anyway inside the function.
