Solution explanation:
In your qiskit code, you are applying the $CX$ gate with the control in the least-significant qubit () and the target in the most-significant qubit (). So, to match your circuit, the definition of the $CX_{q_t q_c}$ gate should be: $$CX_{q_1 q_0} = (I \otimes |0 \rangle \langle 0| + X \otimes |1 \rangle \langle 1|)$$ EDIT: Here is what you end up with assuming your qubit ordering is given as $|q\rangle = |q_1\rangle \otimes |q_0\rangle $ which is in line with qiskit's ordering: $$ \begin{aligned} |q\rangle &= (I \otimes |0 \rangle \langle 0| + X \otimes |1 \rangle \langle 1|)(I \otimes HX)|0\rangle \otimes |0 \rangle \\ \\ |q\rangle &= (I \otimes |0 \rangle \langle 0| + X \otimes |1 \rangle \langle 1|)|0\rangle \otimes |- \rangle \\ \\ |q\rangle &= (I \otimes |0 \rangle \langle 0| + X \otimes |1 \rangle \langle 1|)|0\rangle \otimes \frac{1}{\sqrt{2}}(|0 \rangle - |1 \rangle) \\ \\ |q\rangle &= \frac{1}{\sqrt{2}}(|0\rangle \otimes |0 \rangle \langle 0|(|0 \rangle - |1 \rangle) + |1\rangle \otimes |1 \rangle \langle 1|(|0 \rangle - |1 \rangle)) \\ \\ |q\rangle &= \frac{1}{\sqrt{2}}(|0\rangle \otimes |0 \rangle - |1\rangle \otimes |1 \rangle) \\ \\ \end{aligned} $$ Now, if you run the following code (same as what you have just for the latest version of qiskit), the results agree with this derivation:
