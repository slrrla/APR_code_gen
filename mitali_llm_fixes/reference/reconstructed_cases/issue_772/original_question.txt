Solution explanation:
You can simply merge the lists of qubits from two quantum registers or more as any python lists using "+" sign. For example The result:

```
gate = UnitaryGate(random_unitary(2 ** 4).data, 'RND-U16') qr1 = QuantumRegister(2, 'q') qr2 = QuantumRegister(3, 'a') circ = QuantumCircuit(qr1, qr2) circ.mct(qr1[0:2] + qr2[0:2], qr2[2]) circ.append(gate, qr1[1:2] + qr2[0:3])
```
