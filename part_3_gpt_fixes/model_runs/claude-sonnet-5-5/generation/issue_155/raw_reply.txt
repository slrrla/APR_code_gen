The root cause is that `partial_trace` takes integer qubit indices, not `QuantumRegister` objects. Each register has 2 qubits, laid out in order, so the indices are:

- reg2: 2, 3
- reg4: 6, 7

The smallest fix is to build the index list from the circuit with `qc.find_bit`, which keeps the code tied to the registers instead of hardcoding numbers.

```python
from qiskit import Aer, QuantumCircuit, QuantumRegister, transpile
from qiskit.quantum_info import partial_trace

qc = QuantumCircuit()
reg1 = QuantumRegister(2)
qc.add_register(reg1)
reg2 = QuantumRegister(2)
qc.add_register(reg2)
reg3 = QuantumRegister(2)
qc.add_register(reg3)
reg4 = QuantumRegister(2)
qc.add_register(reg4)

qc.h(reg1[0])
qc.cnot(reg1[0], reg2[0])
qc.h(reg3[0])
qc.x(reg4[0])
qc.cnot(reg3[0], reg4[0])

simulator = Aer.get_backend("aer_simulator")
qc.save_statevector()
transpiled_qc = transpile(qc, simulator)
result = simulator.run(transpiled_qc).result()

# FIX: passed QuantumRegister objects to partial_trace -> pass the integer qubit indices of those registers, because partial_trace only accepts qubit indices
traced_over_registers = [qc.find_bit(q).index for reg in (reg2, reg4) for q in reg]
density_matrix = partial_trace(result.get_statevector(), traced_over_registers)
```
