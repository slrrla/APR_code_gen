`QuantumCircuit.u1` no longer exists in current Qiskit (it was removed in 1.0), so the program crashes before it reaches `transpile`. The fix uses `qc.p`, which applies `PhaseGate`, the same gate as $U_1(\lambda)$.

On the phase question: transpiling `p` to `['rx', 'ry', 'rz']` should give `rz(lam)` with `global_phase = lam/2`. Qiskit tracks that global phase on the circuit, so the full phase of $U_1(\lambda)$ is kept.

```python
from qiskit import QuantumCircuit, transpile

lam = 0.5

qc = QuantumCircuit(1)
# FIX: removed qc.u1 method -> use qc.p (PhaseGate, identical to U1), because u1 no longer exists and p has an rz decomposition that preserves the phase via global_phase
qc.p(lam, 0)

transpiled = transpile(qc, basis_gates=['rx', 'ry', 'rz'])
print(transpiled)
```
