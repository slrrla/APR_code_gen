```python
import numpy as np
import qiskit
from qiskit import *

number_of_qubits = 3
backend_sim = Aer.get_backend('qasm_simulator')

input_circuit = QuantumCircuit(number_of_qubits, number_of_qubits)
input_circuit.x(0)
input_circuit.h(1)
input_circuit.cx(0,1)
input_circuit.i(1)
input_circuit.x(1)
# FIX: circuit had no measurements so classical bits stayed 0 -> added measure of all qubits into classical bits, because counts only reflect measured qubit states
input_circuit.measure(range(number_of_qubits), range(number_of_qubits))

job_sim = execute(input_circuit, backend_sim, shots=1024)
result_sim = job_sim.result()
counts = result_sim.get_counts(input_circuit)
print(counts)
```

The circuit never measured its qubits, so the classical register stayed at its initial `000` no matter which gates you applied. Adding a measurement of all three qubits copies their states into the classical bits. The counts now reflect what the gates actually did.
