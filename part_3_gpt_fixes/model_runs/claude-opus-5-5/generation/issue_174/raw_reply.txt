In OpenQASM 2.0, the condition in an `if` must compare a whole classical register to an integer. Indexed bits like `c[0]` are not allowed there, so the parser rejects `if (c[0]==1)`. Because `creg c[1]` has only one bit, `c==1` tests exactly the same thing as `c[0]==1`, so I changed all six conditions to `if (c==1)`.

On your second question: OpenQASM 2.0 has no conditional blocks or branch statements. Each gate must carry its own `if`, which is why the condition is repeated on every line.

```python
from qiskit import QuantumCircuit, execute
from qiskit import BasicAer as Aer

cloner1 = """
OPENQASM 2.0;
include "qelib1.inc";
qreg q[5];
creg c[1];
x q[2];
x q[4];
x q[0]; //Set up input
measure q[0] -> c[0];
# FIX: indexed bit conditions c[0]==1 are invalid in OpenQASM 2.0 -> use whole-register c==1, because OpenQASM 2.0 'if' only compares an entire creg to an integer (c has one bit so it is equivalent)
if (c==1) CX q[1],q[2];
if (c==1) CX q[2],q[1];
if (c==1) CX q[1],q[2];
if (c==1) CX q[3],q[4];
if (c==1) CX q[4],q[3];
if (c==1) CX q[3],q[4];
measure q[1]->c[0];
measure q[3]->c[0];
"""

circuit = QuantumCircuit.from_qasm_str(cloner1)

backend = Aer.get_backend('qasm_simulator')
job = execute(circuit, backend, shots=1024)
result = job.result()
print(result.get_counts())
```
