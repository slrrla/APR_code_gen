```python
from qiskit import QuantumRegister, ClassicalRegister, QuantumCircuit

n = 4
v = list()
a = QuantumRegister(1, "a")
for i in range(n):
    v.append(QuantumRegister(2, "v" + str(i)))
b = ClassicalRegister(1, "b")

# FIX: passed the list v as a single argument -> unpacked it with *v, because QuantumCircuit expects each register as its own positional argument and rejects a Python list of registers
c = QuantumCircuit(a, *v, b)

```

`QuantumCircuit` takes each register as a separate positional argument. Passing the list `v` as one argument makes it reject the input with a `CircuitError`, because a list is not a register. Writing `*v` spreads the four `QuantumRegister`s out as individual arguments. The circuit then gets the ancilla `a`, then `v0` through `v3`, then the classical register `b`.
