The bug is on the line `-1 * gate1`. `qc.h` is a bound method, not a gate object, so multiplying it by `-1` raises `TypeError`. Even if it ran, the result would not be added to the circuit.

A gate's negative, `-U`, is the same as `U` with a global phase of π, since `e^{iπ} = -1`. To apply it, I build a one-qubit sub-circuit with `global_phase=pi`, put the gate in it, turn that into a gate, and append it to the target qubit. Because the phase is part of the gate itself, it still has an effect when the gate is used inside a larger or controlled operation. I applied it to qubit 1 as an example; the question doesn't say which qubits should get the negated gate.

```python
from qiskit import QuantumCircuit
# FIX: needed pi to express the -1 factor as a global phase e^{i*pi} = -1
from math import pi

qc = QuantumCircuit(2)
qc.h([0, 1])

gate1 = qc.h
# FIX: `-1 * gate1` multiplied a bound method (TypeError) and applied nothing -> build a 1-qubit circuit with global_phase=pi containing the gate, convert it to a gate and append it, because -U equals U with a global phase of pi and as a gate the phase is kept when it is part of a larger/controlled operation
neg_gate1 = QuantumCircuit(1, global_phase=pi)
neg_gate1.h(0)
qc.append(neg_gate1.to_gate(), [1])
```
