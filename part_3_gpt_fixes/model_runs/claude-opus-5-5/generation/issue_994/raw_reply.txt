The error happens because the qasm simulator only stores counts by default, so `get_statevector` has nothing to return. The fix is to add a save-statevector instruction to the circuit.

```python
from qiskit import QuantumCircuit, execute
from qiskit.providers.aer import QasmSimulator

qc = QuantumCircuit(2)
qc.h(0)
qc.cx(0, 1)
# FIX: no statevector was saved in the circuit -> added qc.save_statevector(), because QasmSimulator only returns data from explicit save instructions, so get_statevector fails without it
qc.save_statevector()

backend = QasmSimulator()
backend_options = {"method": "statevector"}

job = execute(qc, backend, backend_options=backend_options)
job_result = job.result()
print(job_result.get_statevector(qc))
```
