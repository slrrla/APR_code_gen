The layout maps two virtual qubits, `qreg[0]` and `qreg[5]`, to the same physical qubit 12. A layout has to be one-to-one. Placing two virtual qubits on one physical qubit makes the transpiler build an invalid graph, which is what raises `DAGCircuitError: 'not a DAG'`. The fix is to give `qreg[5]` its own physical qubit. I chose 16 because no other qubit in the layout uses it.

```python
import qiskit as qk
from qiskit import Aer
from qiskit.ignis.mitigation.measurement import complete_meas_cal

_backend = Aer.get_backend('qasm_simulator')

qreg = qk.QuantumRegister(7)
# FIX: qreg[0] and qreg[5] were both mapped to physical qubit 12 -> mapped qreg[5] to unused qubit 16, because a layout must be one-to-one and duplicates produce an invalid DAG
layout = {qreg[0]: 12, qreg[1]: 11, qreg[2]: 13, qreg[3]: 17, qreg[4]: 14, qreg[5]: 16, qreg[6]: 6}

meas_calibs, state_labels = complete_meas_cal(
    qubit_list=[0, 1, 2], qr=qreg, circlabel='mcal')
print(meas_calibs[0])
qk.compiler.transpile(meas_calibs, backend=_backend, initial_layout=layout)
```
