The bug is that the legacy Aqua `commutator` function doesn't accept `DensityMatrix` objects. The commutator of two matrices is `AB - BA`, so I compute it directly from the `.data` arrays.

```python
from qiskit import QuantumCircuit
from qiskit.quantum_info import DensityMatrix
from qiskit.aqua.operators.legacy import commutator

circ0 = QuantumCircuit(1)
circ1 = QuantumCircuit(1)

circ0.x(0)
dm0 = DensityMatrix.from_instruction(circ0)

circ1.z(0)
dm1 = DensityMatrix.from_instruction(circ1)

# FIX: commutator() from qiskit.aqua legacy does not accept DensityMatrix objects -> compute the matrix commutator AB - BA directly from the .data arrays, because the commutator of two matrices is defined as dm0*dm1 - dm1*dm0
comm = dm0.data @ dm1.data - dm1.data @ dm0.data
```
