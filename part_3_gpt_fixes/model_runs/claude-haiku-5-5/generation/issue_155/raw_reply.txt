The bug is that `partial_trace` expects integer qubit indices, but the code passes `QuantumRegister` objects. The fix converts each register into the indices of its qubits in the circuit.

```python
from qiskit import Aer, QuantumCircuit, QuantumRegister, transpile
from qiskit.quantum_info import partial_trace

qc = QuantumCircuit()
reg1 = QuantumRegister(2)
qc.add_register(reg1)
reg2 = QuantumRegister(2)
qc.add_register(reg2)
reg3 = QuantumRegister(2)
qc.add_register(reg3)
reg4 = QuantumRegister(2)
qc.add_register(reg4)

qc.h(reg1[0])
qc.cnot(reg1[0], reg2[0])
qc.h(reg3[0])
qc.x(reg4[0])
qc.cnot(reg3[0], reg4[0])

simulator = Aer.get_backend("aer_simulator")
qc.save_statevector()
transpiled_qc = transpile(qc, simulator)
result = simulator.run(transpiled_qc).result()

# FIX: partial_trace takes integer qubit indices, but registers were passed -> convert each register's qubits to their circuit indices, because partial_trace needs integer positions
traced_over_registers = [qc.qubits.index(qubit) for reg in [reg2, reg4] for qubit in reg]
density_matrix = partial_trace(result.get_statevector(), traced_over_registers)
```
