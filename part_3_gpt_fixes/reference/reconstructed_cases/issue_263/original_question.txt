Solution explanation:
I didn't check all of your code, but this answer addresses the following: I still need to be able to set the first qubit in an arbitrary state To do this, you can use the function to get a random 1-qubit vector (this vector has dimension 2 so that is why we pass the argument to the function) from the uniform Haar measure. Then, you initialize your first qubit (index 0) to this vector using the method. This method takes as its first argument the vector to initialize to and as its second argument the index of the qubit to initialize.
