Solution explanation:
According to qiskit maintainers, " should work but currently doesn't". In the meantime, transpiling to (using either translation_method?) and then calling the transpiler pass on the output should work. According to qiskit maintainers, and passes should be equivalent, but using directly has less overhead "The pass should be the last pass running in the translation stage", and can simply be appended to the default passes For the moment, it does not seem so. More details in the related issue on qiskit repository.

```
transpile(...., translation_method="synthesis", unitary_synthesis_method="sk")
```
