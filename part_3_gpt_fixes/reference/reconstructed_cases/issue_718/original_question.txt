Solution explanation:
The format that the IBM Quantum API is currently using is Qobj (or Quantum object) which is documented here: https://arxiv.org/abs/1809.03452 and the current schema definitions for it are located here: https://github.com/Qiskit/ibm-quantum-schemas That's just the background information on the format though, to answer the details of your question, Qiskit supports loading this and creating a circuit from a Qobj payload via its class and the function. Assuming you have a local file the basic workflow would be something like: Where is the list of objects equivalent to what's in the qobj (a qobj can contain more than one circuit). and are dictionaries containing the configuration and metadata contained in the qobj.

```
import json from qiskit.assembler.disassemble import disassemble from qiskit.qobj import QasmQobj with open('job.json') as fd: qobj_dict = json.load(fd) qobj = QasmQobj.from_dict(qobj_dict) circuits, run_config, headers = disassemble(qobj)
```
