Solution explanation:
Adding to Frank's answer, you can also create an Instruction for the state vector initialization, using the class, which you can construct passing different arguments (vector, statevectors, etc.). You could then this instruction to your circuit:

```
Initialize
```

```
append
```

```
qc = QuantumCircuit(4) init_gate = Initialize([0.8, 0.6]) qc.append(init_gate, [0])
```

```
qc = QuantumCircuit(4) init_gate = Initialize([0.8, 0.6]) qc.append(init_gate, [0])
```
