Solution explanation:
This behavior is already documented for example here: The command returns a simulator configured to the given noise model. In addition to setting the simulator’s noise model, it also overrides the simulator’s basis gates, according to the gates of the noise model.

```
AerSimulator(noise_model=noise_model)
```

Original fixed code:
AerSimulator(noise_model=noise_model)
