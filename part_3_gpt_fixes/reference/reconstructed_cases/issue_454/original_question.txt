Solution explanation:
Qiskit (and also Aer if I'm not mistaken) requires you to transpile your circuit before passing it to a backend. This can now be done using the pass manager like so: Add these lines before and you should be good to go.

```
pm = generate_preset_pass_manager(backend=backend, optimization_level=1) qc_combine = pm.run(qc_combine)
```
