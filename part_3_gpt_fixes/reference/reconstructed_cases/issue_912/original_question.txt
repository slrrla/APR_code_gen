Solution explanation:
You should be able to do this by simply creating an instance of the class. This can be done as follows There are lot of examples of how to do this in the testing file for these classes.

```
from qiskit.validation import base raw_counts = {'0x0': 4, '0x2': 10} data = models.ExperimentResultData(counts=base.Obj(**raw_counts))
```

```
from qiskit.validation import base raw_counts = {'0x0': 4, '0x2': 10} data = models.ExperimentResultData(counts=base.Obj(**raw_counts))
```
