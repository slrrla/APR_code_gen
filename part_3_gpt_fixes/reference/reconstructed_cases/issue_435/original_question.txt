Solution explanation:
On a simulator it doesn't matter since you would assume that all the qubits are connected. So I assuming you thinking of mapping this onto actual qubit on the hardware. If that is the case, then you can do it through the function. For example: Now, I can remap the qubit when I do my transpilation onto the qubit layout of Athens as follows: Hopefully this is what you were thinking of...

```
transpile
```

```
quanc = QuantumCircuit(5) print(quanc) q_0: q_1: q_2: q_3: q_4:

```
quanc = QuantumCircuit(5) print(quanc) q_0: q_1: q_2: q_3: q_4:
```

```
qc_transpiled= transpile(quanc, backend = provider.get_backend('ibmq_athens') , optimization_level = 3, initial_layout = [4,2,3,0,1] ) qc_transpiled.draw( 'mpl',style={'name': 'bw'}, scale = 0.5)
