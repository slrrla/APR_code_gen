Solution explanation:
You can break all the blocks in a circuit in smaller blocks by using the method.

```
decompose
```

```
from qiskit.circuit.library import RealAmplitudes ansatz = RealAmplitudes(3, reps=2) ansatz.decompose().draw('mpl')
```

```
from qiskit.circuit.library import RealAmplitudes ansatz = RealAmplitudes(3, reps=2) ansatz.decompose().draw('mpl')
```
