Solution explanation:
You can use method: returns a tuple that contains two elements; the first element is the index at which the Bit can be found (in either qubits or clbits according to its type). The second element is a list of (register, index) pairs with an entry for each Register in the circuit which contains the Bit.

```
QuantumCircuit.find_bit()
```

```
print("qargs : ", [qc.find_bit(qarg)[0] for qarg in qargs],"\n")
```
