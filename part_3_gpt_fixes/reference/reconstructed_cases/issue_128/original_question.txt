Solution explanation:
You can specify the target basis for instance using : Note that the target basis should be complete (e.g. ). For high optimization levels (2 or 3) you might have to include and so all optimization passes work correctly. I don't think the Molmer-Sorensen gate is currently supported as basis gate

```
transpile
```

```
from qiskit import transpile target_basis = ['rx', 'ry', 'rz', 'h', 'cx'] decomposed = transpile(circuit, basis_gates=target_basis, optimization_level=0) # 0 for no optimization, 3 is max
```
