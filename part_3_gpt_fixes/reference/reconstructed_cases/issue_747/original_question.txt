Solution explanation:
You are noticing that measurement behavior is different in different versions of Qiskit. In , we have the following behavior: But in the next update there is an error: So your issue is not with the concept per say, but rather you just need to keep notes of the versions in which these changes take place. Clarification: It should also be noted that in the case, the output is reflecting the fact that no measurements have been loaded in to the classical bits (so the values all remain zero). If a measurement statement is included, then this circuit will have GHZ state measurement statistics:
