Solution explanation:
If you want to add previously existing qubits to other register you can obviously compose or append to add previously existing qubits to other register, let's say we have have two qubits who are in state |++> and we want to add them to our register which has for example 4 qubits, we can do You'll get something like this

```
sub_circuit = QuantumCircuit(2) circuit = QuantumCircuit(4) qr = circuit.qregs[0] circuit.x(range(4)) sub_circuit.h(range(2)) circuit = circuit.append(sub_circ.to_instruction(), [qr[0], qr[1]])
```
