Solution explanation:
The way you're using is wrong since it doesn't specify that there are $5$ qubits in your circuit. Instead, you should use it like this: Because Qiskit uses little-endian notation the qubits are ordered from right to left. Alternatively, you can utilize the method as shown here.

```
SparsePauliOp.from_list
```

```
H1 = SparsePauliOp.from_list([("IIZXI", 1),("YIIIY",3)])
```

```
H1 = SparsePauliOp.from_list([("IIZXI", 1),("YIIIY",3)])
```

```
SparsePauliOp.from_sparse_list
```
