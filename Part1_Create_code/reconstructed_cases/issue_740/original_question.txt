Solution explanation:
Some backend configuration is saves an released in Qiskit (being moved to the IBM Quantum packages). You can retrieve that configuration from :

```
qiskit.providers.fake_provider
```

```
from qiskit.providers.fake_provider import FakeLima from qiskit.visualization import plot_error_map backend = FakeLima() plot_error_map(backend)
```
