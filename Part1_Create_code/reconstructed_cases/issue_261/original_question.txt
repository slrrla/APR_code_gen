Solution explanation:
You can simply use Python's function: There are some security concerns regarding you need to be aware of. See here for details.

```
eval()
```

```
from qiskit.opflow import I, X, Y, Z hamiltonian_string = '1*(X^X^X) - 2*(X^Z^X) + 3*(X^I^X)' hamiltonian = eval(hamiltonian_string) print(type(hamiltonian))
```
