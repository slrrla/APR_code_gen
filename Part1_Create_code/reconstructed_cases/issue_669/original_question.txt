Title: Get state vectors in qiskit at any time in a circuit created with initialize() and decompose()

Solution explanation:
You can get the statevector at any point by inserting a instruction at this point. Then simulating the circuit. And you can get the list of instructions in the circuit by using attribute. For example, this code snippet will insert a instruction after the third instruction in your circuit: And this is how to insert a after each instruction: This is another example which shows how to insert a instruction after each layer. This time we are using method: Now, simulate the circuit to get the statevectors: Note Starting from version 0.37, supports a new parameter, , which can be used to specify number of times the circuit should be decomposed. So, instead of these two lines of codes: you can simply use:

from qiskit.providers.aer.library import SaveStatevector num_qubits = qc2.num_qubits for index in range(len(qc2.data) - 1, -1, -1): _inst = SaveStatevector(num_qubits, label = 'psi_' + str(index)) qc2.data.insert(index, [_inst, qc2.qubits, None])

```
from qiskit.converters import circuit_to_dag, dag_to_circuit dag = circuit_to_dag(qc2) new_dag = dag.copy_empty_like() for index, layer in enumerate(dag.layers()): circ = dag_to_circuit(layer['graph']) circ.save_statevector('psi_' + str(index)) layer['graph'] = circuit_to_dag(circ) new_dag.compose(layer['graph']) qc2 = dag_to_circuit(new_dag)
```
