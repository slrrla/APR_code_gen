Solution explanation:
The last is 0.2.2 from January 2021. It is unmaintained since then and their github repo is archived. Based on their file: You can get exactly these with: It should work after that.

```
qiskit-rng
```

```
requirements.txt
```

```
qiskit-ibmq-provider>=0.10 qiskit-terra>=0.16.2
```

pip install "qiskit-terra==0.16.2" pip install "qiskit-ibmq-provider~=0.10"
