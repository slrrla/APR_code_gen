Solution explanation:
This has been resolved now. The above mentioned problem was an issue with 0.3.0 version qiskit_machine_learning library. You can get more details about the issue and how it has been resolved here. TLDR: Install the 0.4.0 developer's version of qiskit_machine_learning library. Clone this repository and from with the folder, run

```
pip install .
```
