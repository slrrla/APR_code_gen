Solution explanation:
You use PauliSumOp to do (for example) the following: You can then pass this object into the VQE instance like you did.

```
from qiskit.opflow.primitive_ops import PauliSumOp paulis = ['IZ', 'XZ', 'YZ', 'ZZ', 'XX'] weights = [1,2,3,4,5] pauli_op = [([pauli,weight]) for pauli,weight in zip(paulis,weights)] hamiltonian = PauliSumOp.from_list([ op for op in pauli_op ])
```
