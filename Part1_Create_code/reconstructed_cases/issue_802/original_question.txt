Solution explanation:
If you have $M$ marked element, then the number of iterations should be $$\frac{\pi}{4}\sqrt{\frac{N}{M}} \text{where},\;\;\; N = 2^n $$ So, you need to replace this line with Note also that, you should use instead of to specify the number of iterations. Check out this answer for the details.

```
iterations = np.pi/4*np.sqrt(2**n)
```
