Solution explanation:
In Qiskit, a knows nothing about the circuit it belongs to. So, can't accept a register to trace over, because it can't identify the subsystem in the given state which corresponds to this register. However, you can easily get the list of circuit qubits which belong to a quantum register or more as follows:

```
QuantumRegister
```

```
partial_trace
```

```
traced_over_qubits = [ qc.qubits.index(qubit) for qubit in reg2[:] + reg4[:] ] density_matrix = partial_trace(result.get_statevector(), traced_over_qubits)
```
