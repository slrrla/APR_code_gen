Solution explanation:
The circuit you are implementing by use of the function, consists of a Hadamard gate followed by a Phase gate of the form: $$ P(2x) = \begin{bmatrix}1 & 0 \\ 0 & e^{2ix} \end{bmatrix} .$$ If you replace your definition of the matrix: with that of a phase gate: and use that to calculate the the , you will get the same answer: To be clear, using an $R_z(2x)$ gate should give you the same answer to that of using a phase gate (up to a global phase), but you are off by a factor of $2$ because the correct matrix for the $R_z(2x)$ gate is: $$ R_z(2x) = \begin{bmatrix}e^{-ix} & 0 \\ 0 & e^{ix} \end{bmatrix} .$$
