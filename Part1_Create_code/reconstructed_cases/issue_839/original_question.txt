Solution explanation:
I think you are right that these two attributes are supposed to the same. Looking at the git history, was used prior to this PR: https://github.com/Qiskit/qiskit-terra/pull/6418 but the usage was removed during the refactoring in that PR. Prior to #6418, was set by which in turn was set by . in https://github.com/Qiskit/qiskit-terra/blob/5ec42789171b001780239d9e03e5dba4e077aa40/qiskit/algorithms/minimum_eigen_solvers/vqe.py in https://github.com/Qiskit/qiskit-terra/blob/5ec42789171b001780239d9e03e5dba4e077aa40/qiskit/algorithms/variational_algorithm.py#L229-L239 After #6418, are directly set by and therefore the intermediate are no longer used. https://github.com/Qiskit/qiskit-terra/blob/dd7f9390cf076f9545fa6086de486f2c06764ea5/qiskit/algorithms/minimum_eigen_solvers/vqe.py#L546-L556
