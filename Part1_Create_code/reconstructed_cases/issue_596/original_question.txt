Solution explanation:
By default, will return a copy of the circuit with the bound parameters. The circuit instance itself will not be modified. To modify it you will need to call it as follows:

```
QuantumCircuit.assign_parameters()
```

```
qc.assign_parameters(bind_dict, inplace = True)
```

```
qc.assign_parameters(bind_dict, inplace = True)
```

QuantumCircuit.assign_parameters()
