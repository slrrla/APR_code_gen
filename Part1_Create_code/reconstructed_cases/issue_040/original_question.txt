Solution explanation:
From what I can tell, this information isn't available from the provider because the parameter isn't supplied to the constructor. This might be worth submitting an issue or PR for! In the meantime, you can get per-shot results by getting the Amazon Braket task result directly:

```
header
```

```
ExperimentResult
```

```
from braket.aws import AwsQuantumTask task = AwsQuantumTask(job.job_id()) measurements = task.result().measurements
```

```
from braket.aws import AwsQuantumTask task = AwsQuantumTask(job.job_id()) measurements = task.result().measurements
```
