Solution explanation:
It is a bug. And it has been reported several times before. Here are some workarounds to overcome this issue. Try the one you prefer: Add the sub-circuits using instead of : Transpile the circuit into elementary gates: If you prefer to keep the structure of the saved circuit as close as possible to the original circuit, you can the gates that cause the issue only: Add the missing definition(s) to Qasm:
