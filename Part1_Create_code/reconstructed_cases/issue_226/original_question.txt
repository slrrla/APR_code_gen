Solution explanation:
The class has a method: https://qiskit.org/documentation/stubs/qiskit.quantum_info.Operator.html?highlight=operator%20from_label#qiskit.quantum_info.Operator.from_label That means you could do something like this: It's possible to add and into N-sized . However, you have to call the by hand:

```
op = 0 * Operator.from_label('I' * N) # Set the initial operator to zero op = op._add(opZZ, qargs=[i,j]) op = op._add(opZ, qargs=[k])
```
