Solution explanation:
Although sets the maximum number of CPU cores used by OpenMP for parallelization during execution of an experiment, there are other factors that affect the amount of parallelization that will actually occur. Most notably, your circuit must have at least 14 qubits. You can control this value using 's option. The following example demonstrates how to take advantage of having multiple cores. Let's create 200 circuits: Then we transpile them: Now, we configure the backend for parallelization and run the circuits: Note that: equal 0 means use all the CPU cores. equal 0 means maximum number of experiments that may be executed in parallel equals value. equal 1 means disable parallel shot execution. equal 16 (default) means that number of qubits in the circuit must be greater than 16 to enable parallelization for matrix multiplication during execution. Note that enabling parallelization to small circuits can reduce performance.
