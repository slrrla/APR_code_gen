Solution explanation:
In Qiskit you can get the controlled version of any gate with the method . For S and T, here is the example: If you want to compare these gates with or , you can use the class:

```
control
```

```
from qiskit.circuit.library.standard_gates import SGate, TGate csgate = SGate().control(1) # the parameter is the amount of control points you want ctgate = TGate().control(1) circuit = QuantumCircuit(2) circuit.append(csgate, [0, 1]) circuit.append(ctgate, [0, 1]) print(circuit)
```
