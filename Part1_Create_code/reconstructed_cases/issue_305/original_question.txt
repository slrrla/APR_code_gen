Title: Calculate expectation value using Qiskit Simulator and Estimator

I define a random circuit and want to measure the observable. I calculate the expectation value using Estimator and Simulator. However, the results are different. Where is the mistake?

```
# Define the base circuit qc = QuantumCircuit(3) qc.h(2) qc.cx(2, 1) qc.x(0) qc.cx(0, 2) # Define the measurement circuit # It transforms Z basis to X basis qc_mes = QuantumCircuit(3) qc_mes.h(0) qc_mes.h(1) qc_mes.h(2) # Combine base with measurement circuit qc_all = qc.copy() qc_all.compose(qc_mes, inplace=True) num_shots = 10000 backend = Aer.get_backend("qasm_simulator") # Use estimator to run the circuit estimator = Estimator(backend, options={"default_shots": int(1e4)}) op = SparsePauliOp.from_list( [ ("XXX", (-105.8)), ] ) job = estimator.run([(qc, op)]) measured_energy = job.result()[0].data.evs print('estimator expectation val:', measured_energy) # Use simulator to run the circuit qc_all.measure_all() job2 = backend.run(qc_all, shots=num_shots) job2_res = job2.result().get_counts() exp_cal = 0 for key, val in job2_res.items(): if key.count('1') % 2 == 0: exp_cal += val else: exp_cal -= val exp_cal = exp_cal * (-105.8) / num_shots print('calculated expectation val:', exp_cal)

Solution explanation:
Your code is correct, and both methods actually perform the same task, as expected. The discrepancies that you see are rather an artifact on the low number of shots that you use w.r.t. your observable. Indeed, the expectation value that you should see is $0$. However, by multiplying your observable by $-105.8$, you drastically increase the variance of the end result. Let $\sigma^2$ be the variance of the random variable whose mean we want to estimate. In our case, since the mean is nil, we get $$\sigma^2=\langle\psi|(XXX)^2|\psi\rangle=1\,.$$ This in turn means that the variance of our estimate will be $\frac{1}{N}$, using $N$ shots. However, if you multiply $XXX$ by a factor $x$, then the variance of our estimate will this time be $\frac{x^2}{N}$. Thus, in order to get a somewhat good precision, you should set $N$ to a larger order of magnitude than $x^2$, in this case around $10^4$. By setting $N=10^6$, this ensures a variance of around $10^{-2}$, meaning a standard deviation of around $10^{-1}$, and we do see both estimates converging to $0$. from qiskit import QuantumCircuit from qiskit_aer import AerSimulator from qiskit_ibm_runtime import Estimator from qiskit.quantum_info import SparsePauliOp qc = QuantumCircuit(3) qc.h(2) qc.cx(2, 1) qc.x(0) qc.cx(0, 2) # Define the measurement circuit # It transforms Z basis to X basis qc_mes = QuantumCircuit(3) qc_mes.h(0) qc_mes.h(1) qc_mes.h(2) # Combine base with measurement circuit qc_all = qc.copy() qc_all.compose(qc_mes, inplace=True) num_shots = 1_000_000 backend = AerSimulator(method="statevector") # Use estimator to run the circuit estimator = Estimator(backend, options={"default_shots": int(1e6)}) op = SparsePauliOp.from_list( [ ("XXX", (-105.8)), ] ) job = estimator.run([(qc, op)]) measured_energy = job.result()[0].data.evs print('estimator expectation val:', measured_energy) # Use simulator to run the circuit qc_all.measure_all() job2 = backend.run(qc_all, shots=num_shots) job2_res = job2.result().get_counts() exp_cal = 0 for key, val in job2_res.items(): if key.count('1') % 2 == 0: exp_cal += val else: exp_cal -= val exp_cal = exp_cal * (-105.8) / num_shots print('calculated expectation val:', exp_cal)
```
