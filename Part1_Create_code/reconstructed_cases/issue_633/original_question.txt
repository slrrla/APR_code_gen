Solution explanation:
The method is exactly what you are searching for. Adding at the end of your code snippet illustrates how to use it. On my benchmarks, it is faster than but still way slower than : I suspect that copying the statevector is the costly part, but I have no data to backup my claim.

```
QuantumCircuit.set_statevector
```

```
from qiskit.quantum_info import Statevector qc_3 = QuantumCircuit(16) qc_3.set_statevector(state_vec) start = time.time() for i in range(1000): result = simulator.run(qc_3).result() time_3 = time.time() - start print(f"time took to run circuit w set_statevector {1000} times: {round(time_3,3)}s")
```
