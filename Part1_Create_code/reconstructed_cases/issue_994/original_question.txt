Solution explanation:
If you're using the class from Aer it does not generate a state vector result. The method you passed in as a backend option is the simulation method/technique that Aer will use for simulating the circuit, but it is still the QASM simulator which is expected to return measurement counts not a statevector. You can see a description of the different simulation methods in the Docs. When you were calling that returns a backend object which will simulate the circuit and return the state vector at the end of the execution and return that in the result, which is why works there. If you want to get the state vector while using the you can use the instruction in your circuit which will return the state vector at that point in the circuit. Although, if you do this the state vector won't be returned by (that will still fail) it will be in the snapshots under .
