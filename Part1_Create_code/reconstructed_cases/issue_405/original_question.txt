Solution explanation:
The reason why its not working is because you are transpiling the circuit. Your circuit before transpiling looks like this: But after you run your circuit changes to this: Notice how there is no gate to apply the error on. The reason for this is, because gate does nothing to the qubit, the transpiler pass will remove it so that there are less gates to run which means less error will be introduced. But if you want to apply error just use the non-transpiled circuit. So your code changes to: This will result in a histogram which looks something like this: Your code was working correctly for is becasue won't get rid of the from the circuit.
