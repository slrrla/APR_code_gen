Title: The magic square game in qiskit

I am working on the magic square game as presented on p. 21 of this paper by Brassard, Broadbent and Tapp. I am going for a simulation of ideal quantum systems first, without noise. I have successfully implemented it in QCircuits, so I know it works. Now I try do the same in Qiskit using StatevectorSimulator to simulate ideal circuits. This is the code, which is a minor modification of this code from github. When I run it, most of the time the output looks like this The row indicates that the game master asked for row 3 and column 2, Alice produced row [1, 0, 1], while Bob produced column [1, 0, 0] and the common entry at (3,2) being 0 means Alice and Bob win this round. The row indicates that the game master asked for row 3 and column 2, Alice produced row [0, 0, 0], while Bob produced column [1, 1, 1] and the common entries at (3,2) are 0 for Alice and 1 for Bob meaning that they loose this round. Strangely, when the requested row and column coincide, the simulation yields 100% wins as far as I checked the simulations. Only when they are different, there seem to be losses approximately averaging out at 50%. I double checked the operators, the initialization, the reconstruction of row and column from the quantum measurement, but I could not find any mistakes. Question: Does anybody know what is wrong? Why do I not get 100% success all the time with this code?

Solution explanation:
It seems you are applying the operators to the wrong set of qubits. Your operators should be on qubits and the operators on qubits . In ket notation, the most common way to organize qubits (and the one qiskit uses) is: $$|q\rangle = |q_3 q_2 q_1 q_0\rangle.$$ Following the way you have setup the conditions for this problem, you want the operators to act on the two qubits most to the left, and the operators to act on the two qubits most to the right.
