Solution explanation:
If , then the controlled $RY$ gets applied to the target qubit if the control qubit is in state $|1\rangle$. Similarly, if , then the controlled $RY$ gets applied to the target qubit if the control qubit is in state $|0\rangle$. This can be seen very naturally when you express these gates in their matrix form. For the matrix with , you have: $$CRY = I\otimes|0\rangle\langle0| + RY\otimes|1\rangle\langle1|$$ For the matrix with , you have: $$\bar{C}RY = RY\otimes|0\rangle\langle0| + I\otimes|1\rangle\langle1|$$
