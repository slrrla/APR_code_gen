Solution explanation:
Sure, you can do this with reduce but your list needs to also have the information about which registers you are composing onto. So if your circ_list was a list of tuples where the first component was the circuit object and the second component was a list indicating which registers this circuit will be composed onto like [2,3] Then you should be able to use reduce as: See the docs on reduce for more description: https://docs.python.org/3/library/functools.html#functools.reduce

```
reduce(lambda x,y: x.compose(y[0],y[1]),circ_list, qcl)
```

reduce(lambda x,y: x.compose(y[0],y[1]),circ_list, qcl)
