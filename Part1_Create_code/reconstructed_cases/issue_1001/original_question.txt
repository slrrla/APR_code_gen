Solution explanation:
Qiskit's class processes warnings through a logger from the package, not through the package, so suppressing warnings as in other answers won't help. However, each method in provides a parameter; it defaults to but you can set it to to prevent the warnings from being logged. Example:

```
NoiseModel
```

```
logging
```

```
warnings
```

```
NoiseModel
```

```
warnings
```

```
True
```

```
False
```

```
myNoiseModel.add_quantum_error(..., warnings=False)
```
