You can't use because it does not accept . You can, however, implement $(X \otimes X)^\alpha$ using the parameterized gate $R_{xx}(\theta)$ $$R_{xx}(\theta)=\exp(-i\frac{\theta}{2}X \otimes X)$$ We have, $R_{xx}(\pi)=iX \otimes X$. So, $(X \otimes X)^\alpha$ is equivalent to $R_{xx}(\pi\alpha)$ up to a global phase. Hence, instead of: which causes the error, you can write: Or, if you don't want to have a global phase difference: Similarly, you can use $R_{yy}$ and $R_{zz}$ to implement $(Y \otimes Y)^\alpha$ and $(Z \otimes Z)^\alpha$ respectively using the fact that, $R_{yy}(\pi)=iY \otimes Y$, and $R_{zz}(\pi)=-Z \otimes Z$
