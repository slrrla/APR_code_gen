Solution explanation:
I still run into this issue too. If you consider $|q0\rangle$ to be the most significant bit (MSB) you have to map it to the most significant classical bit as well, which is in your case a bit no. 2. Or you can flip your quatnum circuit upside down and then $|q0\rangle$ become the least significant bit (LSB) and the measurement will meet your expectation. A code is valid in case $|q0\rangle$ is LSB and in case $|q0\rangle$ is MSB. I think that the reason for this arrangement is simply a convention, so you can choose whether $|q0\rangle$ is MSB or LSB and set the measurement procedure accordingly.

```
circuit.measure([0,1,2], [0,1,2])
```

```
circuit.measure([0,1,2], [0,1,2])
```

```
circuit.measure([0,1,2], [2,1,0])
```

```
circuit.measure([0,1,2], [2,1,0])
```
