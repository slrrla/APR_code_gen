Title: How to assign and manipulate Qiskit's TwoLocal ParameterVector?

Solution explanation:
Check out the method in Qiskit docs. The simplest way to assign numerical values to each $\theta[i]$ in your parameter vector $\theta$ is to call passing an array-like object (values are bounded to parameters in alphabetical order):

```
QuantumCircuit.assign_parameters
```

```
assign_parameters
```

```
import numpy as np num_pars = len(circuit.parameters) values = np.random.rand(num_pars) new_circuit = circuit.assign_parameters(values)
```
