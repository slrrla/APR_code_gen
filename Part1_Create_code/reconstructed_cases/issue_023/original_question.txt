Title: Qiskit RealAmplitudes changes bits ordering

I use qiskit 1.1.2. The RealAmplitudes circuit should be the identity operator if all the parameters are set to zero. Is that right? Even for 3-qbit system, the Statevectors seem to change when evolved by this circuit. For example taking Statevector as a pure state corresponding to some binary string, I obtain a different pure state. The simplest example of this behaviour can be reconstructed using the following instructions: Why the states (present in probability distribution) are labeled differently? How can I fix it?

