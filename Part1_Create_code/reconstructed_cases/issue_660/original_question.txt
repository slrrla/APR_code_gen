Solution explanation:
The in need to be instantiated then you can call their method. e.g. So instead of the optimizer internally being created via a name passed to the argument of scipy (where name is one of the optimizers available via scipy) here you create an instance and configure it via the constructor parameters, and use the minimize method on that instance.

```
optimizers
```

```
Qiskit
```

```
minimize()
```

```
from qiskit.algorithms.optimizers import SPSA opt = SPSA(maxiter=300) res = opt.minimize(expectation, [1.0, 1.0])
```

```
from qiskit.algorithms.optimizers import SPSA opt = SPSA(maxiter=300) res = opt.minimize(expectation, [1.0, 1.0])
```
