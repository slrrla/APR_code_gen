Title: Using Qiskit AerSimulator with an NVIDIA GPU

I am trying to use my NVIDIA GPU to enhance my ability to simulate Qiskit. I've got a simple Qiskit circuit that I would like to simulate in a Python venv on VSCode, using my OS: Pop!_OS 22.04. My GPU is an NVIDIA RTX 3060, running driver version 565.77 with CUDA 12.7 I am using nvcc, version 11.5 My Python venv contains qiskit-aer-gpu, cuQuantum and cuTensor among other things. Calling torch.cuda.is_available() inside my venv returns 'False', while I believe it should return 'True' if everything were correct. When I attempt to simulate my circuit using AerSimulator(method="Statevector", device="GPU"), I receive a RuntimeError: "No CUDA device available!". What I can do to allow the GPU to be used; I can simulate just fine using my CPU. How might I be able to progress forward? I've seen How can we access GPU to execute qiskit codes. If possible give me a sample code, which seemed to be a similar issue. But I've not managed to derive a solution.
