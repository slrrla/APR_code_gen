Solution explanation:
Note that $2^{20}=1048576$. The reason why tries to allocate a $2^{20}\times2^{20}$ array is not in order to store the final state vector, but in order to represent the which, when applied on the $|0\rangle$ state, will provide the final state vector. This circuit is a unitary matrix of size $2^{20}\times2^{20}$, which is the reason why tries to allocate an array of this size. Of course, one might argue that there is no need to allocate the unitary matrix since the quantum circuit is only made out of a single gate, but doesn't know this. All in all, as soon as you use Statevector on a with 20 qubits, you'll run into this issue, because of how works.
