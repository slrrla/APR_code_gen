Solution explanation:
I think the gate that you're looking for is the qiskit gate. Its understandable to be unsure as I've heard multiple terms used for the same gate. In pytket it is called . The qiskit library calls it . The name Mølmer–Sørensen gate or MS gate is used frequently too. According to the docs the unitary for the in qiskit is $$ R_{XX}(\theta) = \exp\big(-i \frac{\theta}{2} X \otimes X\big)\,. $$
