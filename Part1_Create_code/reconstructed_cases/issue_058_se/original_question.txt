Solution explanation:
You have to transpile your circuit before running it. So, before calling you have to add the following: This is because your circuit contains a composite gate (the one created by method) which in turn contains another composite gate () . Qiskit transpiler will unroll these gates to one- and two-qubit gates, then translate these gates into gates from the target backend's basis gate set.

```
backend.run
```

```
from qiskit import transpile circuit = transpile(circuit, backend=backend)
```
