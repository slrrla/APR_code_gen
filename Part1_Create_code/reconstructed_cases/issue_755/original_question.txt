Solution explanation:
Note that qiskit orders qubits oppositely from what you might have expected: it uses the "little endian" convention. This is explained in (slightly) greater detail in previous questions such as this one. The function on statevector is not giving you the dimensions of the vector. It is giving you a list of the dimensions of the individual quantum systems. Here you have two qubits (i.e. each of dimension 2).
