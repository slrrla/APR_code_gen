Solution explanation:
You need to do to get a dictionary of the counts returned by the circuit. You would do this as follows Using your circuit and this code, will look something like . From there you might want to extract the key which has a higher value to be the result of your coin flip.

```
.get_counts()
```

```
job = execute(circuit, backend = simulator, shots=100) result = job.result() counts_dict = result.get_counts()
```

```
job = execute(circuit, backend = simulator, shots=100) result = job.result() counts_dict = result.get_counts()
```

