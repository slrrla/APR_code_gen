Solution explanation:
You can do this with or . I'll show a simple example. Here I've constructed my object using Statevector.from_label but you should be able to construct it however you like and plug it into . resets all qubits to the $|0\rangle$ state before state preparation. does not add resets.

```
QuantumCircuit.prepare_state
```

```
QuantumCircuit.initialize
```

```
from qiskit import QuantumCircuit from qiskit.quantum_info import Statevector state = Statevector.from_label("+-rl") qc = QuantumCircuit(4) qc.prepare_state(state, [0, 1, 2, 3])
```

```
from qiskit import QuantumCircuit from qiskit.quantum_info import Statevector state = Statevector.from_label("+-rl") qc = QuantumCircuit(4) qc.prepare_state(state, [0, 1, 2, 3])
```
