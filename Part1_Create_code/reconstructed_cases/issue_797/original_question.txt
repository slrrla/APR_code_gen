Solution explanation:
You can take only the keys of the returned dictionary: If you want only one random key, you can just take the first one in the set: or store all the keys in a list and take a random one from here:

```
measurements = set(counts.keys()) print(measurements)
```

```
measurements = set(counts.keys()) print(measurements)
```

```
random_key = next(iter(a))
```

```
random_key = next(iter(a))
```

```
from random import randint measurements_list = list(measurements) random_key = measurement_list[randint(0, len(measurement_list)-1)]
```
