Solution explanation:
You need to add the number of qubits for the initial state, this worked for me : You can also pass a list for the initial point, for example : You can even pass a circuit for the initial point, there : If you need something else feel free to ask ! :)

```
n_qubits = 2 #or whatever you want for your example qaoa_mes = QAOA(H, p=p, optimizer=optimizer, initial_state = Zero(n_qubits), quantum_instance=Aer.get_backend("qasm_simulator"))
```

```
n_qubits = 2 #or whatever you want for your example qaoa_mes = QAOA(H, p=p, optimizer=optimizer, initial_state = Zero(n_qubits), quantum_instance=Aer.get_backend("qasm_simulator"))
```

```
qaoa_mes = QAOA(H, p=p, optimizer=optimizer, initial_state = [0.,0.], quantum_instance=Aer.get_backend("qasm_simulator"))
```

```
qaoa_mes = QAOA(H, p=p, optimizer=optimizer, initial_state = [0.,0.], quantum_instance=Aer.get_backend("qasm_simulator"))
```

```
n_qubits = 2 initial = QuantumCircuit(n_qubits) #add any gate you want in the circuit, for example : initial.h(0) initial.cx(0,1) qaoa_mes = QAOA(H, p=p, optimizer=optimizer, initial_state = initial, quantum_instance=Aer.get_backend("qasm_simulator"))
```
