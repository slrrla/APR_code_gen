Solution explanation:
It depends on your local environment and local configuration. By default if you're running on Linux with Python < 3.9 or macOS with Python < 3.8 then passing mutiple circuit's to will run in multiple process locally. This is done using Python's to launch parallel processes and call transpile on each circuit in the input list in the process pool. The code for how Qiskit does this is in: https://github.com/Qiskit/qiskit-terra/blob/0.18.2/qiskit/tools/parallel.py (the function is what uses under the covers when you pass in >1 circuit). Also, the defaults are adjustable so if you run on windows or with a newer python version you can still run in parallel but it's not enabled by default because there were some issues found using python's module in those environments. You can refer to https://qiskit.org/documentation/configuration.html on how to set the options controlling parallelism.
