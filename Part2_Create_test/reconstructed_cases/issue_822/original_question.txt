Solution explanation:
Controlled-H is not one of the basis gates of . You can get this list of gates using: So, you need to transpile the circuit into the supported set of gates before running it: Notes: There is no need to call . Actually, passing an assembled qobj directly to the method of the Aer simulator backends has been deprecated in favor of passing transpiled circuits directly. Using function also works because is called internally.
