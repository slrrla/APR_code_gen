Solution explanation:
You are missing an important part of the preparation process of the circuit for it to run on the simulator (any backend, actually) : the transpilation. In order to create the qobj, you first have to transpile your circuit into gates your backend "understands", kind of like a translator between your custom gates and the basis gates of the backend. First you do the transpile of the circuit to transform it into gates the backends knows, then you assemble it into a obj to be able to run it. So for your code to run here, you would have to do something like this: You can also use the function that does it for you: Hope this is clear enough, if you have any questions about this please let me know in the comments :)

```
# Create a Qobj from the circuit for the simulator to run test = transpile(circuit, svsim) qobj = assemble(test) # Do the simulation, return the result and get the state vector result = svsim.run(qobj).result().get_statevector()
```
