Title: RX gate in series

I have to apply two Rx gates in series. How do I do it?

```
from qiskit import QuantumRegister, ClassicalRegister from qiskit import QuantumCircuit import numpy as np q = QuantumRegister(1,'q') circuit = QuantumCircuit(q,c) A=circuit.rx(np.pi/2,q[0]) circuit.rx(np.pi/2,A) circuit.measure(q,c) print(circuit)
```

Solution explanation:
There is no need to make the following assignment: and then pass as an argument to the next application. You simply run the method twice with the corresponding angles you want to apply:

```
A=circuit.rx(np.pi/2,q[0])
```
