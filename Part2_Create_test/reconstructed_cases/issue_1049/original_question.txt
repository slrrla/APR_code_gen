Solution explanation:
It is unclear how you want to identify the location of each U3 gate, but assuming you have a plan for how to do that, here's a simple solution. I am using the class in qiskit because I can't run your code since it is incomplete ( is not defined). Here's the circuit I used: The code below iterates over the circuits, assigns a label to each it encounters and creates a dictionary of dictionaries where the keys are the gate labels, and the values are dictionaries with the qubit and parameter information of each gate: For the example above, it produces the following output

from qiskit import transpile from qiskit.circuit.library import QuantumVolume qc = QuantumVolume(2) tqc=transpile(qc, optimization_level=3, basis_gates=["u3", "cx"], seed_transpiler=1) tqc.draw()

gate_val = 0 u3_dir = {} for i, instruction in enumerate(tqc.data): if instruction.operation.name == 'u3': u3_dir['u3_'+str(gate_val)] = {'qubit':instruction.qubits[0], 'params': instruction.operation.params} gate_val +=1

```
gate_val = 0 u3_dir = {} for i, instruction in enumerate(tqc.data): if instruction.operation.name == 'u3': u3_dir['u3_'+str(gate_val)] = {'qubit':instruction.qubits[0], 'params': instruction.operation.params} gate_val +=1
```
