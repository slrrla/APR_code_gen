Solution explanation:
Replace with: This makes a custom measurement instruction that measures the 3 qubits together, as per https://github.com/Qiskit/qiskit-aer/issues/319. After doing this, you will find it both favors 000 over 111 and also there will be sporadic instances of the other computational basis states:

```
meas.measure(range(3), range(3))
```

```
meas.measure(range(3), range(3))
```

```
meas.append(Instruction("measure", 3, 3, []), range(3), range(3))
```
