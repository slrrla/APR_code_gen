## 별도 검토 대상

### 157: FIXED_CONTRACT_MISMATCH — 12개 버전 모두

buggy는 Initialize의 reset 때문에 controlled gate 변환에 실패한다. fixed는 이 변환 문제를 해결하고, 상태 준비 검사는 전역 위상을 허용하면 통과한다.
그러나 buggy의 `control(2)`를 fixed가 `control()`로 바꿔 제어 큐비트가 2개에서 1개로 줄고 전체 게이트 크기도 4에서 3큐비트가 된다.
원래 인터페이스를 보존하는 별도 검사는 실패한다. 제공된 답변 예제 자체도 1개 제어를 사용하므로, 이는 상태 준비 알고리즘 전체가 틀렸다는 판정이 아니라 데이터셋의 입출력 계약 불일치에 대한 검토 요청이다.
fixed.py는 수정하지 않았다. 엑셀 `Fixed failures` 시트에 버전별 실패 테스트와 원인을 기록했다.

### 233: RECONSTRUCTION_NOTE — 27개 버전 모두

재구성 buggy는 정수 속성인 `num_parameters_settable`을 함수처럼 호출하여 TypeError가 난다.
따라서 원래 질문의 파라미터 수 갱신 문제에 도달하기 전에 실패한다. fixed의 출력과 독립 바인딩은 모든 지정 버전에서 통과했다.

### 315: DIFFERENT_BUGGY_ERROR — 0.45.0 / 0.45.1 / 0.45.2 / 0.45.3

Qiskit 0.45.x에서는 BasicProvider 모듈이 없어 import 단계에서 실패한다.
0.46.x 및 지정 1.x/2.x에서는 원래 이슈인 병렬화 옵션 미지원 오류에 도달한다. fixed는 23개 버전 전부 통과했다.
2.x 실행에 필요한 psutil은 기존 Batch 01의 작업별 보조 패키지 경로로 공급했다. 공유 Qiskit/Aer/NumPy 패키지는 변경하지 않았다.
처음 발생한 보조 패키지 접근 제한은 권한이 있는 로컬 재실행으로 해소했고, 최종 보고서에는 유효한 재실행 결과를 반영했다.
