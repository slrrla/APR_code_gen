The circuit prepares a GHZ state but never measures it, so the classical bits are never filled and the `get_counts` result is not a meaningful measurement record. Adding an explicit measurement of all three qubits into the three classical bits fixes this.

```python
from qiskit import Aer
from qiskit import execute
from qiskit import QuantumCircuit

circ = QuantumCircuit(3, 3)
circ.h(0)
circ.cx(0, 1)
circ.cx(0, 2)
# FIX: circuit had no measurement, so classical bits were never populated -> added measure of all qubits into the classical register, because counts must come from measured outcomes
circ.measure([0, 1, 2], [0, 1, 2])

backend = Aer.get_backend("qasm_simulator")
job = execute(circ, backend, shots=100000)
result = job.result()
counts = result.get_counts(circ)
print(counts)
```
