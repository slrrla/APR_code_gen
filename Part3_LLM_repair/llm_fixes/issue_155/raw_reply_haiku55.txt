The root cause is that `partial_trace` takes integer qubit indices, not register objects. Passing `QuantumRegister`s makes it try to compare them with `>`, which fails. I replaced the register list with the qubit indices of those registers, looked up in the circuit's qubit list.

```python
from qiskit import Aer, QuantumCircuit, QuantumRegister, transpile
from qiskit.quantum_info import partial_trace

qc = QuantumCircuit()
reg1 = QuantumRegister(2)
qc.add_register(reg1)
reg2 = QuantumRegister(2)
qc.add_register(reg2)
reg3 = QuantumRegister(2)
qc.add_register(reg3)
reg4 = QuantumRegister(2)
qc.add_register(reg4)

qc.h(reg1[0])
qc.cnot(reg1[0], reg2[0])
qc.h(reg3[0])
qc.x(reg4[0])
qc.cnot(reg3[0], reg4[0])

simulator = Aer.get_backend("aer_simulator")
qc.save_statevector()
transpiled_qc = transpile(qc, simulator)
result = simulator.run(transpiled_qc).result()

# FIX: partial_trace was given QuantumRegister objects, but it needs integer qubit indices -> convert the registers to the indices of their qubits in the circuit, because partial_trace compares qargs as integers
traced_over_registers = [qc.qubits.index(q) for reg in [reg2, reg4] for q in reg]
density_matrix = partial_trace(result.get_statevector(), traced_over_registers)
```
