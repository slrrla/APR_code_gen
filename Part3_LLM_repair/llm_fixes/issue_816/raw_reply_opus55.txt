Root cause: `result.get_memory(circ)` raises an error because per-shot results were never stored. The run call is missing `memory=True`, which tells the simulator to keep each shot's classical bitstring. The fix adds that argument to the `run` call.

```python
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator

circ = QuantumCircuit(2, 2)
circ.h(0)
circ.cx(0, 1)
circ.measure([0, 1], [0, 1])

simulator = AerSimulator()

# FIX: run without memory=True -> added memory=True, because get_memory requires per-shot results to be stored
result = simulator.run(circ, shots=10, memory=True).result()
memory = result.get_memory(circ)
print(memory)
```
