`initialize` is not a unitary gate: it starts with `reset` operations on the qubits. That makes the circuit non-unitary, so `to_gate()` fails, and the result could not be controlled anyway. The fix is to use `prepare_state`, which applies only the unitary `StatePreparation` gate, so it can be turned into a gate and controlled. This assumes the target qubits start in |00⟩, which is what `initialize` would reset them to.

```python
from qiskit import QuantumCircuit

state = [0.5, 0.5, 0.5, 0.5]

qc_gate = QuantumCircuit(2)
# FIX: initialize (non-unitary, includes reset) -> prepare_state, because StatePreparation is a unitary gate that can be converted with to_gate() and controlled
qc_gate.prepare_state(state, [0, 1])

gate = qc_gate.to_gate().control(2)

```
