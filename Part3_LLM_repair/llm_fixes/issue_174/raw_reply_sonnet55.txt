The bug is in the OpenQASM 2.0 source. `if` conditions must compare a whole classical register, so `if (c[0]==1)` is rejected. The fix is to write `if (c==1)` on each conditional line. The register `c` has a single bit, so this tests the same value.

```python
from qiskit import QuantumCircuit, execute
from qiskit import BasicAer as Aer

cloner1 = """
OPENQASM 2.0;
include "qelib1.inc";
qreg q[5];
creg c[1];
x q[2];
x q[4];
x q[0]; //Set up input
measure q[0] -> c[0];
// FIX: OpenQASM 2.0 'if' cannot index a register bit (c[0]) -> compare the whole register (c==1), because the condition must use the register name and c has only one bit
if (c==1) CX q[1],q[2];
// FIX: OpenQASM 2.0 'if' cannot index a register bit (c[0]) -> compare the whole register (c==1), because the condition must use the register name and c has only one bit
if (c==1) CX q[2],q[1];
// FIX: OpenQASM 2.0 'if' cannot index a register bit (c[0]) -> compare the whole register (c==1), because the condition must use the register name and c has only one bit
if (c==1) CX q[1],q[2];
// FIX: OpenQASM 2.0 'if' cannot index a register bit (c[0]) -> compare the whole register (c==1), because the condition must use the register name and c has only one bit
if (c==1) CX q[3],q[4];
// FIX: OpenQASM 2.0 'if' cannot index a register bit (c[0]) -> compare the whole register (c==1), because the condition must use the register name and c has only one bit
if (c==1) CX q[4],q[3];
// FIX: OpenQASM 2.0 'if' cannot index a register bit (c[0]) -> compare the whole register (c==1), because the condition must use the register name and c has only one bit
if (c==1) CX q[3],q[4];
measure q[1]->c[0];
measure q[3]->c[0];
"""

circuit = QuantumCircuit.from_qasm_str(cloner1)

backend = Aer.get_backend('qasm_simulator')
job = execute(circuit, backend, shots=1024)
result = job.result()
print(result.get_counts())
```
