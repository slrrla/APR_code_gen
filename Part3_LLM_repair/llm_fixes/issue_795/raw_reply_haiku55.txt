The root cause is that `circuit.append(...)` with an opflow operator adds a non-gate instruction, so `to_gate()` fails. The fix converts the operator to its matrix and adds it with `circuit.unitary`, which creates a real gate. The operator is unitary (it is a real rotation), so this is valid.

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit.opflow import I, X, Y, Z

circuit = QuantumCircuit(1, name='R')
# FIX: appended a non-gate opflow operator directly to the circuit, so to_gate() fails -> add its unitary matrix via circuit.unitary, because unitary() creates a proper gate instruction
circuit.unitary((0.5*I - 1j*np.sqrt(1-0.5**2)*Y).to_matrix(), [0])
circuit.to_gate()
```
