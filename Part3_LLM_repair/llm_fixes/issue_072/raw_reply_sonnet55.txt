The layout maps both `qreg[0]` and `qreg[5]` to physical qubit 12. A layout must be one-to-one, so the transpiler cannot build a valid DAG from it and raises "not a DAG". Giving `qreg[5]` a physical qubit that no other virtual qubit uses fixes it.

The unused physical qubits are 0–10, 15, 16 and so on, so I picked 15. The simulator backend has no coupling map, so any distinct index would work in principle. The "12" at `qreg[5]` was most likely a typo.

```python
import qiskit as qk
from qiskit import Aer
from qiskit.ignis.mitigation.measurement import complete_meas_cal

_backend = Aer.get_backend('qasm_simulator')

qreg = qk.QuantumRegister(7)
# FIX: qreg[5] and qreg[0] were both mapped to physical qubit 12 -> mapped qreg[5] to unused physical qubit 15, because a layout must be one-to-one for the transpiler to build a valid DAG
layout = {qreg[0]: 12, qreg[1]: 11, qreg[2]: 13, qreg[3]: 17, qreg[4]: 14, qreg[5]: 15, qreg[6]: 6}

meas_calibs, state_labels = complete_meas_cal(
    qubit_list=[0, 1, 2], qr=qreg, circlabel='mcal')
print(meas_calibs[0])
qk.compiler.transpile(meas_calibs, backend=_backend, initial_layout=layout)
```
