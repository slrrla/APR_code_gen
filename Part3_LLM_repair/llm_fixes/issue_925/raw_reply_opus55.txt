The Aqua `Shor` circuit needs `4n + 2` qubits, not the `2n + 3` from the paper. For N = 15, `n = 4`, so it needs 18 qubits. That cannot be transpiled onto the 15-qubit Melbourne coupling map. The fix is to run on a backend with enough qubits.

```python
from qiskit.aqua.algorithms import Shor
from qiskit.aqua import QuantumInstance
# FIX: imported a 15-qubit FakeMelbourne -> import BasicAer, because the Aqua Shor circuit needs 4n+2 = 18 qubits for N=15
from qiskit import BasicAer

PRIME = 15

# FIX: FakeMelbourne (15 qubits) backend -> BasicAer qasm_simulator, because the 18-qubit circuit exceeds Melbourne's coupling map
backend = BasicAer.get_backend('qasm_simulator')
quantum_instance = QuantumInstance(backend, skip_qobj_validation=False)

shor = Shor(PRIME, 2)
res = shor.run(quantum_instance)
print("The list of factors of {} as computed by Shor is {}.".format(PRIME, res['factors'][0]))
```
