Solution explanation:
Note that for the first state you have $$ \dfrac{|11 \rangle - |10\rangle}{\sqrt{2}} = -|1\rangle \otimes \dfrac{|0 \rangle - |1\rangle}{\sqrt{2}} $$ This is a product or separable state. Hence no entanglement and therefore you don't need a two qubit gate. Recall the mapping $X|0\rangle =|1\rangle$ and and $Z|1\rangle = -|1\rangle$ and $H|1\rangle = \dfrac{|0 \rangle - |1\rangle}{\sqrt{2}} $ So you are looking for something like ** Note the circuit is in little endian convention (read from bottom to top). You should be able to get the second one now.
