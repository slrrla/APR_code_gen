Solution explanation:
You can convert a operator to a operator easily by passing it as a parameter to constructor:

```
qiskit.quantum_info
```

```
qiskit.opflow
```

```
PrimitiveOp
```

```
from qiskit.opflow import PrimitiveOp # |+> sv = Statevector.from_label('+') # |+><+| proj = sv.to_operator() # Convert to opflow operator: op = PrimitiveOp(proj)
```

```

```
