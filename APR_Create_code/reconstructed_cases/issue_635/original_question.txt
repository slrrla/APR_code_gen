Solution explanation:
AFAIK, what you want can't be run on the hardware right now. See this github issue. However, you can do this in the simulators. If, for example, and make up a two-bit classical register , you can do this:

```
c[0]
```

```
c[1]
```

```
c
```

```
qc.x(q[0]).c_if(c,3) qc.x(q[1]).c_if(c,3)
```

```
qc.x(q[0]).c_if(c,3) qc.x(q[1]).c_if(c,3)
```
