Title: SAT solver simulation by qiskit works wrong

I tried to build a qiskit QuantumCircuit solving k-SAT problems. However, the result seems wrong comparing with the heuristic SAT solver, PySAT. The first code defines kSAT function for k maximum size of clause, n variables, and m number of clauses. The problem matrix formularizes kSAT problem. For example, $$f=(x_1 \lor x_2)\land (\neg x_1 \lor x_3)\land (x_2 \lor x_3)$$ is represented by $$[[1,1,0]\\ [-1,0,1]\\ [0,1,1]]$$ This is an example of 3-SAT problem (with n=4, m=20) However, the result seems wrong {'1011': 137} You can test the problem with the PySAT Could you explain what's wrong and how to debug this kind of error?

```
from qiskit import QuantumCircuit from qiskit.circuit.library import MCXGate from qiskit_aer.primitives import SamplerV2 def kSAT(k=3, n=3, m=3): qc = QuantumCircuit(n + m + 1, n + m +1) qc.x(range(n, n + m)) qc.h(range(n)) # Problem matrix generation: \{-1,0,1\}^{m \times n} matrix = np.zeros((m, n), dtype=int) non_zero_indices = [] for row in range(m): non_zero_indices.append(np.random.choice(n, size=k, replace=False)) matrix[row, non_zero_indices[row]] = np.random.choice([-1, 1], size=k) problem = matrix print(problem) # De morgan's law inverse_problem = -1 * problem for i in range(m): for j in range(n): if inverse_problem[i][j] == -1: qc.x(j) target = non_zero_indices[i].tolist() mcx = MCXGate(3) qc.mcx(target, n + i) qc.barrier() qc.mcx(list(range(n,n+m)), n+m) return qc, problem k=3 n=4 m=20 qc, problem = kSAT(k, n, m) qc.measure(range(n + m+1), range(n+m+1)) qc.draw('mpl')
```
