Solution explanation:
As per Qiskit's release notes, under "IBM Q Provider 0.12.0"[1] method now takes one or more or . Use of and is now deprecated. So, you shouldn't call . Just pass the transpiled circuits to method: I tested this code using the latest Qiskit version and it worked without any problem. The backend was (it is the backend returned by function when I called it)

```
qiskit.providers.ibmq.IBMQBackend.run()
```
