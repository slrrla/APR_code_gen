Solution explanation:
Qiskit distinguishes operations into unitary operations ("gates") and operations that are not necessarily unitary ("instructions"). In your workflow you end up with an object on the circuit, therefore it cannot be converted to a . Since you're trying to construct a gate essentially from a matrix, you could instead use Alternatively, you could construct the unitary directly

```
qiskit.circuit.Instruction
```

```
qiskit.circuit.Gate
```

```
U = (0.5*I - 1j*np.sqrt(1-0.5**2)*Y).to_matrix() circuit.unitary(U, [0]) gate = circuit.to_gate()
```

```
U = (0.5*I - 1j*np.sqrt(1-0.5**2)*Y).to_matrix() circuit.unitary(U, [0]) gate = circuit.to_gate()
```

```
from qiskit.extensions import UnitaryGate gate = UnitaryGate(U) # U from above
```
