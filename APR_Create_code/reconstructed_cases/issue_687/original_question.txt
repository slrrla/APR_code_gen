Solution explanation:
These "circuit" gates are empty, if you transpile the circuit to a basis gate set they will disappear: As the answer of @viwosh points out, that behavior is also fixed in the newer versions of Qiskit.

```
from qiskit import transpile circ = # your circuit transpiled = transpile(circ, basis_gates=["h", "s", "sdg", "rz", "cx"]) print(transpiled.draw())
```

