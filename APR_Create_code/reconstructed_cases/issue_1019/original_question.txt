Solution explanation:
Each has a attribute that is also accessible through each . So, you can do the following to match the circuits to the measurement counts after running in parallel: Before running your circuits, you could also assign your own descriptive names, e.g. Edit: Combining the ideas above to show how to order the results:

```
qiskit.QuantumCircuit

```
```
for circuit in qcircuits: print(circuit.name) result_dict = jobs.result().to_dict()["results"] result_counts = jobs.result().get_counts() for i in range(len(qcircuits)): name = result_dict[i]["header"]["name"] counts = result_counts[i] print(f"{name}: {counts}")
```

```
# number input circuits in ascending order for i in range(len(qcircuits)): qcircuits[i].name = "circuit_"+str(i) job = qiskit.execute(qcircuits, backend, ...) result_dict = job.result().to_dict()["results"] result_counts = job.result().get_counts() # initialize list to store ordered results results_ordered = [None] * len(qcircuits) for i in range(len(qcircuits)): name = result_dict[i]["header"]["name"] n = int(name.split('_')[1]) # index of circuit in input list results_ordered[n] = result_counts[i] # add to result list at same index
```
