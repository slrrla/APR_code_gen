Solution explanation:
The decomposition they give is the following: $$ R_z(\theta) = R_x\left(\pi / 2\right) R_y(\theta) R_x\left(-\pi / 2\right) $$ Therefore, the Qiskit code would look like: Which gives output: And we can see it is equivalent to $R_z(\theta)$:

```
from qiskit import QuantumCircuit from qiskit.quantum_info import Operator import numpy as np theta = np.pi / 4 qc = QuantumCircuit(1) qc.rx(-np.pi / 2, 0) qc.ry(theta, 0) qc.rx(np.pi / 2, 0) Operator(qc).data
```
